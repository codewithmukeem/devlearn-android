# Changelog

All notable changes to the DevLearn project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-09-05

### Added
- **Complete Multi-Language Tracks**:
  - **C Programming Track**: 8 chapters covering 15 comprehensive lessons (from compilation lifecycle to pointers and dynamic memory management).
  - **C++ Programming Track**: 6 chapters covering 10 lessons (modern C++17/20, RAII, smart pointers, OOP, templates, STL).
  - **Java Programming Track**: 5 chapters covering 8 lessons (JVM architecture, OOP, class inheritance, exception handling).
  - **Android Development Track**: 5 chapters covering 7 lessons (Kotlin foundations, Jetpack Compose, state hoisting, Room database).
- **Interactive Code Playground**: Embedded code execution environment for practicing algorithms and syntax directly on mobile.
- **Formative Quizzes**: Chapter-end knowledge check quizzes with immediate explanation feedback.
- **Offline Persistence**: Room SQLite database preserving user lesson completion, quiz streaks, and learning statistics.
- **Material 3 Theming**: Dynamic theme switching, edge-to-edge layout, fluid typography, and accessible touch targets.
- **APK Production Release**: Pre-compiled Android application package attached to GitHub releases.
